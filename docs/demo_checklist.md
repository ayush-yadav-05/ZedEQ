# Demo Checklist

1. Create the Vivado project with `vivado_create_project.tcl`.
2. Confirm the top module is `top_zedboard_eq`.
3. Generate bitstream and program the ZedBoard.
4. Connect line audio input to the ZedBoard audio input.
5. Connect headphones or speakers to the audio output.
6. Connect a 3.3 V USB-UART adapter to PMOD JA1 and JA2.
7. Start `gui/eq_gui.py`.
8. Select the serial port and connect.
9. Move the five EQ sliders and volume slider.
10. Check LD0-LD7 for live output level.
